  • Vulnerabilities are affected packages in the install tree, as reported by npm audit. Next.js bundles many dependencies into dist/compiled, and those are checked too. Raw npm audit leaves them out.
  • Advisories are distinct GitHub security advisories matched anywhere in the install tree. One advisory can flag every package that depends on the affected one, and one package can have several advisories, so this can be higher or lower than Vulnerabilities.
  • Dependencies are unique name@version pairs across the whole ecosystem, installed together in one tree. Shared dependencies count once per version. Platform-specific builds of a native package (one per OS and CPU) count once. Third-party means not published by the framework’s npm organization.
  • Past dates only count advisories published by that date.
  • Snapshots are fresh installs, which pick up the newest patch releases each package allows.
